## 2) Backend Breakdown

## backend/.env

- Environment variables for backend runtime.
- Stores sensitive/service config values such as SECRET_KEY, DB credentials, and server settings.

## backend/main.py

- Backend application entry point.
- Creates FastAPI app instance and metadata.
- Configures CORS.
- Registers all API routers.
- Exposes health-check endpoint.
- Starts Uvicorn server in local execution mode.

## backend/requirements.txt

- Python dependency manifest.
- Defines backend packages: FastAPI, SQLAlchemy, JWT/security libs, PostgreSQL driver, Redis client, Alembic, etc.

## backend/venv/

- Local Python virtual environment.
- Contains installed packages and Python binaries for isolated development.

## backend/**pycache**/

- Python bytecode cache.
- Auto-generated by Python runtime.

---

### backend/app/

Core backend package containing all business modules.

## backend/app/**init**.py

- Package initializer for app module.
- Empty marker file; enables Python package import behavior.

### backend/app/api/

Route/controller layer. Defines HTTP and websocket endpoints.

## backend/app/api/auth.py

- Authentication API.
- User registration endpoint.
- Login endpoint (OAuth2 password form), verifies credentials and returns JWT token + basic user context.

## backend/app/api/arenas.py

- Arena domain APIs.
- Public discovery listing endpoint.
- Discovery join handling (public immediate vs private pending).
- Arena creation.
- Join by invite code.
- List logged-in user arenas.
- List arena members and related community metadata.

## backend/app/api/activity.py

- Activity and proof-validation APIs.
- Submit daily proof with same-day duplicate prevention.
- Vote on proofs (upvote/downvote, switch/undo logic).
- Auto-flag absent status based on downvote threshold.
- Arena history endpoint returning submissions + messages timeline.

## backend/app/api/admin_arena.py

- Admin control APIs for arena owners.
- Fetch pending join requests.
- Approve/reject membership requests.
- Remove existing members.
- Generate invite assets (invite code/link/QR payload data).

## backend/app/api/profile.py

- User profile APIs.
- Fetch profile with optional arena-context role (admin/member view).
- Password change endpoint.

## backend/app/api/deps.py

- Shared dependency utilities for routes.
- OAuth2 bearer token extraction and JWT decoding.
- Current-user resolution from token and DB.

## backend/app/api/websocket.py

- Real-time communication endpoint.
- Arena-scoped websocket connection management.
- Broadcasts chat messages to connected room clients.
- Persists incoming chat messages in database through CRUD layer.

## backend/app/api/**pycache**/

- Auto-generated Python bytecode cache for API modules.

### backend/app/core/

Infrastructure and platform foundation for backend.

## backend/app/core/config.py

- Centralized settings class using pydantic-settings.
- Loads environment variables from backend/.env.
- Builds computed SQLAlchemy database URI safely (password encoding).

## backend/app/core/database.py

- SQLAlchemy engine/session/base setup.
- Defines SessionLocal factory.
- Defines get_db dependency for request-scoped DB session lifecycle.

## backend/app/core/security.py

- Security primitives.
- Password hashing and verification (bcrypt via passlib).
- JWT access token creation with expiry and signing configuration.

## backend/app/core/init_db.py

- Utility script to initialize/create DB tables.
- Imports model classes into metadata registry.
- Calls Base.metadata.create_all for bootstrapping.

## backend/app/core/**pycache**/

- Auto-generated Python bytecode cache.

1. Start with architecture split:

- "This project is a full-stack product with FastAPI backend + Next.js frontend."

2. Explain backend layering:

- "API routes handle transport, CRUD layer handles data access, core layer manages config/security/database, and models/schemas define persistence and contracts."

3. Explain key product modules:

- "Authentication, arena lifecycle, proof submission workflow, peer verification voting, admin moderation, and realtime chat."

4. Explain frontend route strategy:

- "Next.js App Router with route-based pages: landing, auth, dashboard, dynamic arena room, and profile."

5. Explain production hygiene:

- "Config is environment-driven, linting/typing is enabled, and dependencies are locked for reproducible builds."

## 5) Interview Tip for File-Wise Questions

If interviewer asks "why this file exists", answer using this structure:

- Responsibility: what this file owns.
- Boundary: what this file deliberately does not own.
- Contract: which layer/file it communicates with.

Example:

- arenas.py owns arena HTTP endpoints.
- It does not own DB schema or token decoding internals.
- It interacts with models/CRUD/dependency-injected user context.
